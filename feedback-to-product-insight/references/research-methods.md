# 研究方法选择

根据未知项选择最低成本且能影响决策的方法。

| 未知项 | 优先方法 | 适合回答 |
|---|---|---|
| 用户如何完成当前任务 | 流程访谈、情境观察 | 真实步骤、替代工具、摩擦点 |
| 事件发生频率与变化过程 | 日记研究、行为日志 | 频率、触发条件、时间序列 |
| 用户是否理解或接受方案 | 概念测试 | 价值理解、方案偏好、主要顾虑 |
| 用户能否顺利完成交互 | 可用性测试 | 成功率、错误点、交互成本 |
| 功能是否改变行为结果 | Wizard-of-Oz、受控 MVP | 采纳率、完成率、重复使用 |
| 权限与自动化接受边界 | 分级授权测试、情景访谈 | 可接受的读取、写入和确认等级 |
| 解释是否提升信任或采纳 | 解释形式对比测试 | 理解度、采纳率、错误识别 |
| 付费意愿 | 价值测试、价格敏感度研究 | 支付触发点、替代成本、价格区间 |

## 研究优先级

- `P0`：会决定 MVP 是否值得做、核心范围或安全边界。
- `P1`：会影响交互方案、用户分群或下一版本范围。
- `P2`：优化性问题，不阻碍当前核心决策。

每项建议都要说明：要验证的假设、目标用户、核心提问或任务，以及不同结果如何改变产品决策。
